How it works

Users differ, and many sensors remember past movements. We remove the sensor memory in hardware and align users in software.

1

Wear

A liquid-metal fibre strain sensor (FLSF) runs along two fingers. Its resistance follows the current strain, not past movements.

2

Calibrate once

One 60 s recording without gesture labels. CapX encodes how this user's signals relate to hand joints, without updating model weights.

3

Use

The same gesture from different users lands in one shared space. No weight updates for the new user.

Using it

Real devices and a real-time hand simulator, driven by two sensor channels.
